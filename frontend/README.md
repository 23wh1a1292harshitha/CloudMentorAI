# Frontend

Owner: Whole team (each person builds the UI for their own module)

The live prototype is `ai-buddy-live.html`: login, quizzes, mastery progress, and AI Buddy chat.

## Setup

1. Start AI Buddy on port 4000 and Testing Engine on port 4001 (same `JWT_SECRET` in both `.env` files).
2. Open `ai-buddy-live.html` in a browser (or serve the `frontend/` folder with any static server).

React + Tailwind remains the planned production UI.
